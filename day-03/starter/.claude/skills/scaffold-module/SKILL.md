# Scaffold one FX1 module

## Use this skill when

The task creates or extends one module in the FX1 project.

## Read first

1. Read `modules/<mine>/SPEC.md`.
2. Read `modules/<mine>/OUTPUT-CONTRACT.json`.
3. Read `../day-02/data/fx1-sample.json`.
4. Read `modules/<mine>/CONFLICTS.md`.

## Procedure

1. List the required fields from the output contract.
2. Map each field to a source field or a formula.
3. Create the smallest output that meets every acceptance criterion.
4. Keep derived values as calculations from base fields.
5. Run the end-to-end check from `SPEC.md`.
6. Record the command and result.

## Result

Give the output path, the check command, and the check result.
